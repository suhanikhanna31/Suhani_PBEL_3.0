SIGNAL

Behavioral & psycholinguistic insider-threat detection. This system watches how people write and who they talk to — not file transfers, not login logs — and turns statistical drift from a person's own baseline into a ranked, explainable signal for a human analyst. It never acts autonomously. Eight independent detection signals run underneath. Scroll through each.

01 / 08 Self-baseline drift

Linguistic & stylometric drift

Every message is scored against that person's own recent history — not a population average, not a fixed rulebook. A sudden swing in tone, urgency, or writing "fingerprint" only matters relative to what's normal for that individual.

The idea

Sentiment, subjectivity, urgency-phrase density, readability, lexical diversity, and function-word/POS ratios form a per-message feature vector. None of these alone means much; the shape of the vector relative to a person's own recent normal is the signal.

The tech

A hand-rolled SlidingWindowStats (bounded-window Welford's variant) keeps an O(1)-amortized running mean/variance per user per feature — src/dsa/sliding_window.py. Sentiment via DistilBERT/TextBlob fallback, POS via spaCy/NLTK fallback — src/features/.

02 / 08 Manipulation-technique detection

Categorized social-engineering lexicon

Not one flat "urgency" bucket — five distinct manipulation techniques, each scanned independently: authority spoofing, isolation/secrecy framing, artificial scarcity, trust exploitation, curiosity baiting.

The idea

Drawn from the standard attention-warfare / media-literacy taxonomy of manipulation techniques, so a flagged message reads as "authority spoofing", not just an opaque score — an analyst can see which kind of pressure the language resembles.

The tech

One Aho-Corasick automaton per category (src/dsa/trie_phrase_matcher.py, reused unchanged) — O(text length + matches) per scan, independent of lexicon size. src/dsa/social_engineering_lexicon.py.

03 / 08 Label-free signals

Unsupervised anomaly detection

A real deployment has no ground-truth insider labels. Two label-free models run as independent signals, not a fallback — an analyst sees where they agree and where they don't.

The idea

IsolationForest flags individual messages as statistical outliers in feature space. DBSCAN clusters users by their aggregate behavioral profile — anyone outside a dense peer cluster (label == -1) is structurally different from everyone else.

The tech

scikit-learn's IsolationForest (message-level) and DBSCAN (user-level) — src/models/unsupervised/anomaly_detection.py, surfaced alongside drift score on every dashboard row.

04 / 08 Agentic AI

Agentic investigation loop

Given a flagged pseudonym, an agent plans and executes a short sequence of read-only tool calls, accumulates evidence, and reasons over all of it before proposing one next step. It never acts.

The idea

Risk summary → recent messages → prior audit events → watsonx.ai explanation → governance-doc search → a single recommendation: escalate_for_manual_review | continue_monitoring | no_action_needed. requires_human_review: true is hard-coded, not a toggle.

The tech

src/agents/investigation_agent.py — every tool has no import path to any write/enforcement code; watsonx.ai reasons over accumulated evidence when configured, with a transparent rule-based fallback otherwise.

05 / 08 Privacy-first design

Governance & privacy architecture

Consent-gated. Pseudonymized, not just anonymized. Raw content never persists. Every decision written to a tamper-evident, hash-chained audit log.

The idea

Salted HMAC-SHA256 replaces every username before a single feature is computed. Re-identification requires the salt, held outside the system. A RAG endpoint answers "how does this system behave" questions grounded only in the real docs and audit log — never a guess.

The tech

src/data/anonymize.py, src/governance/audit_log.py (hash-chained, verify_chain()), src/governance/rag.py (TF-IDF + cosine similarity — no vector DB, fits the free-tier memory budget).

06 / 08 New — social topology

Communication-network drift

Every other signal on this page asks what or how someone writes. This one asks a structurally different question: who are they talking to, and has that circle changed shape? Social withdrawal — a shrinking, more concentrated communication circle — is one of the best-documented pre-incident behaviors in real counterintelligence casework.

The idea

Two features, replayed over the same sliding window as the linguistic baseline: contact_degree (distinct people talked to) and interaction_concentration (a Herfindahl-style index — rising toward 1.0 means almost every message goes to one person). Both feed the exact same baseline + weighted z-score pipeline as sentiment or urgency — no bespoke scoring path.

The tech

A hand-rolled dict-of-dicts adjacency graph — no networkx, zero new dependencies — with a bounded per-sender deque for the sliding window: O(1) average-case edge update. src/dsa/communication_graph.py + src/features/network_features.py.

07 / 08 New — rate of change

Drift trajectory & acceleration

A threshold alone can't tell a three-month slow creep from a one-week sharp spike — even when both end at the same drift level, they read very differently to a human analyst.

The idea

Fit a linear trend across a user's own chronological drift-score sequence (least-squares, far less sensitive to single-message noise than a two-point delta). Compare the trend slope of the window's two halves for a coarse acceleration signal — is the rate of drift itself increasing?

The tech

numpy.polyfit, degree 1, over each user's drift-score history — pure numpy, zero new dependencies. src/features/trajectory.py, merged onto the existing per-user risk table.

08 / 08 New — alert-fatigue defense

Context-aware alert suppression

Is this person's problem, or everyone's? If the whole org's baseline shifts together — layoff rumors, a crunch period — every individual rides that shift into looking anomalous relative to their own history, even though nothing about them personally changed.

The idea

Gates individual escalation on standing relative to this run's own, possibly also-elevated, population — not absolute drift alone. When an org-wide feature-distribution shift is detected, the cohort-outlier bar is raised, so correlated non-individual events don't cause an alert-fatigue cascade of "escalate" recommendations.

The tech

Pure pandas logic reading the existing OpenScale-style monitoring snapshot (src/governance/openscale_monitor.py) to gate src/governance/alert_suppression.py — no new model, no new dependency, a policy decision layered over signals already computed.
